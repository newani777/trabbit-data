# trabbit-data

트래빗 앱이 매일 읽는 **정적 데이터**입니다. 앱 소스는 여기 없습니다.

| 파일 | 내용 | 출처 |
|---|---|---|
| `weather.json` | 서울 오늘 최저·최고·하늘상태·강수확률 | 기상청 단기예보 (공공데이터포털) |
| `rates.json` | 원화 환율 (주요 통화) | 한국수출입은행 |

## 왜 저장소에 두나

앱이 기상청·은행 API 를 직접 부르면 호출 수가 사용자 수에 비례하고 인증키가
앱 안에 들어갑니다. 그래서 **하루 한 번 여기서 구워** 앱은 이 파일만 받아 갑니다.
호출 수는 사용자가 몇 명이든 하루 한 번이고, 인증키는 이 저장소의 비밀값에만
있습니다.

굽는 일은 `.github/workflows/bake.yml` 이 매일 06:00(KST)에 합니다.

## 주소

```
https://newani777.github.io/trabbit-data/weather.json
https://newani777.github.io/trabbit-data/rates.json
```

데이터는 기상청·한국수출입은행의 공개 정보이며, 각 기관의 이용약관을 따릅니다.

## 2026-09-11 추가

- `weather.json` 에 `hourly`(지금부터 36시간, 1시간 간격)와 `air`(에어코리아 미세먼지
  예보, 서울 오늘·내일)가 붙는다. 옛 앱은 모르는 키를 무시한다. `air` 는 공공데이터포털
  「한국환경공단_에어코리아_대기오염정보」 활용신청이 승인돼야 생긴다(같은 키).
- `kpop_shows.json` — 이번 달·다음 달 서울 대중음악 공연. 저장소 비밀값 `KOPIS_KEY` 가
  있을 때만 굽는다.
- `weekly_feed/manifest.json` + 회차 폴더 — 앱 「이번 주 한국」(가칭) 카드. 손으로 올리지
  않는다: 트래빗 저장소의 `scripts/publish_weekly_feed.py --id <회차>` 를 쓴다.
