# trabbit-data

트래빗 앱이 매일 읽는 **정적 데이터**입니다. 앱 소스는 여기 없습니다.

| 파일 | 내용 | 출처 |
|---|---|---|
| `weather.json` | 서울 오늘 최저·최고·하늘상태·강수확률 | 기상청 단기예보 (공공데이터포털) |
| `rates.json` | 원화 환율 (주요 통화) | 한국수출입은행 |

## 왜 저장소에 두나

앱이 기상청·은행 API 를 직접 부르면 호출 수가 사용자 수에 비례하고 인증키가
앱 안에 들어갑니다. 그래서 **하루 한 번 여기서 구워** 앱은 이 파일만 받아 갑니다.
호출 수는 사용자가 몇 명이든 하루 한 번이고, 인증키는 이 저장소의 비밀값에만
있습니다.

굽는 일은 `.github/workflows/bake.yml` 이 매일 06:00(KST)에 합니다.
